## ✨ Key Features

### 🕰️ Dynamic Time & Environment System
* **Real-time World Changes:** สภาพแวดล้อมและพื้นหลังของสถานที่ต่างๆ (บ้าน, โรงเรียน, ร้านค้า, ที่ทำงาน) เปลี่ยนแปลงอัตโนมัติอิงตามช่วงเวลาในเกม (เช้า, กลางวัน, เย็น, กลางคืน)
* **Time-Specific Events:** ระบบเงื่อนไขเวลาที่สมจริง เช่น การจำกัดเวลาเข้าถึงโรงเรียน หรือฉากพิเศษของ NPC ที่จะปลดล็อกตามช่วงเวลาที่กำหนดเท่านั้น

### 💬 Deep NPC & Relationship Mechanics
* **Interactive Conversations:** ระบบพูดคุยโต้ตอบกับ NPC (Galadriel, Lazel, Arwen) พร้อมตัวเลือก (Choices) ที่ส่งผลต่อทิศทางของเนื้อเรื่อง
* **Relationship & Gift System:** ระบบความสัมพันธ์ที่พัฒนาได้ผ่านการพูดคุยและการให้ของขวัญ เพื่อปลดล็อก Special Scenes และฉากจบของแต่ละตัวละคร
* **Dynamic Character Expressions:** ภาพ Sprite ของตัวละครเปลี่ยนสีหน้า ท่าทาง และอารมณ์ตามบริบทของบทสนทนา

### ⚔️ Interactive Mini-Games (Blacksmith)
* **Action-Based Crafting:** มินิเกมตีดาบที่มาพร้อมระบบตัวคูณเงิน (Multiplier System) ยิ่งกดได้แม่นยำยิ่งได้รับรางวัลตอบแทนสูง
* **Immersive Feedback:** ตอบสนองผู้เล่นแบบเรียลไทม์ด้วย Sound Effects สัมผัสการตีดาบ และระบบแจ้งเตือนเมื่อพลังงาน (Energy) หมด

### 🎒 RPG Elements & Inventory Management
* **Status & Energy Tracking:** แถบ Status Bar แสดงพลังงานแบบเรียลไทม์ พร้อมระบบลด/ฟื้นฟูพลังงาน (เช่น การนอนหลับเพื่อ Reset Energy)
* **Dynamic Inventory:** กระเป๋าเก็บของที่มาพร้อมระบบ List Item และฟังก์ชันเลื่อน Scroll ดูของในช่องเก็บของ
* **Shop & Economy:** ระบบร้านค้าสำหรับซื้อขายไอเทม (เช่น ดาบ) พร้อม UI ยืนยันการสั่งซื้อที่ชัดเจน

### 🎨 Modern & Responsive UI/UX
* **Adaptive Scaling:** รองรับการแสดงผลหน้าจอทั้งแบบ 100% และ 125% โดยที่ Layout ไม่ทับซ้อนกัน
* **Interactive Elements:** ปุ่มและสถานที่ต่างๆ ในแผนที่มีระบบ Hover Effects, การเปลี่ยนสี และเสียงประกอบเมื่อโต้ตอบ
* **Smooth Transitions:** ระบบ Fade-in / Fade-out ระหว่างเปลี่ยน Scene เพื่อความลื่นไหลของเกมเพลย์
* **QoL Features:** มีหน้า Pause Menu (กด ESC), ระบบแจ้งเตือน (Notify Messages) และ Cheat Code System (กด F12) สำหรับนักพัฒนาหรือผู้เล่นที่ต้องการทดสอบเกม
